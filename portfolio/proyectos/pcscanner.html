PCScanner

Relevamiento de hardware para el servicio técnico.

Estado
Publicado
Autoría
Proyecto personal.
Herramientas
PowerShell, BAT, HTML

Problema

Para diagnosticar o presupuestar una computadora hace falta saber qué tiene, y el cliente no siempre lo sabe.

Qué hice

  • Consulta del sistema, memoria, almacenamiento y otros componentes con CIM/WMI.
  • Armado de un resumen listo para enviar.

Límites

  • Algunos datos dependen del hardware y de los permisos del equipo.
